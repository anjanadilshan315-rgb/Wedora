Forever — The Gilded Celebration (Standard Package Frontend Demo)

Open index.html in a browser or use VS Code Live Server.
Edit names, dates and text in index.html. Edit event dates/venues/maps and RSVP deadline in script.js (CONFIG).
Replace sample remote gallery image URLs with your own pre-shoot images.
To enable music, place a licensed audio file at assets/background-music.mp3.

Features: animated opening, responsive design, gallery, story, event cards and separate maps, countdown, personalized guest URL (?guest=Name), demo RSVP (localStorage), copy link, WhatsApp reminder, public QR code, optional audio.

LIMITATIONS: RSVP is local-browser only and is NOT real guest management. No customer dashboard, central database, authentication, filters or secure per-guest access. Guest names in URL are display-only, not secure invitation tokens. QR uses an external API and works properly only after publishing the invitation online. Replace placeholder date/venue/map/photo content before production. Use a backend/database for real guest management and editable dashboard.
